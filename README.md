# University Projects 

This repository contains a collection of my university coursework and engineering projects, showcasing my practical experience across machine learning, embedded systems, control systems, and real-time simulation. Each project involved hands-on coding, system design, testing, and reporting, demonstrating my growth as a control systems and software engineer.

## Projects

### 1. Smart Burglar Alarm System
**Technologies:** C++, MATLAB, Arduino MEGA

A Group Project where we combined software and hardware to create a fully functioning burglar alarm system with multiple settings. We followed strict Systems engineering principles throughout this project.


### 2. Rapid Control Prototyping of a Helicopter
**Technologies:** MATLAB,Simulink, NI myDAQ, LabVIEW
Developed and tested control strategies for a helicopter pitch and elevation model. Designed both simulated and real-world closed-loop control systems using MATLAB/Simulink, with system identification and real-time implementation.


### 3. Machine Learning Regression Project
**Technologies:** MATLAB  
Explored and implemented various regression techniques on a dataset for predictive modelling. Evaluated model performance and selected the optimal fit using visual and statistical metrics.


### 4. Real-Time Embedded Systems Coursework
**Technologies:** C++, STM32, Keil uVision  
Designed an embedded application with multiple threads handling concurrent tasks. Demonstrated effective use of scheduling and timing in a real-time context.
